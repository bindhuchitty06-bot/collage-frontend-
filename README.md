# Bindhu Institute of Technology (BIT) — Official University Web Portal

A human-crafted, vibrant, dynamic, and fully interactive college web portal for **BIT (Bindhu Institute of Technology)**, featuring multi-campus exploration (Bengaluru, Hyderabad, Chennai, Pune), 24/7 student counseling with Priya Sharma, an interactive tuition & scholarship calculator, and digital campus visit pass generation.

---

## 🌟 Key Highlights & Features

- 📍 **Multi-Campus Location Selector**:
  - **Bengaluru**: Silicon AI & Autonomous Robotics Flagship (Electronic City Phase 1)
  - **Hyderabad**: Cloud Architecture, Quantum Computing & FinTech (Gachibowli)
  - **Chennai**: EV Mobility, Marine Robotics & Green Energy (OMR Tech Expressway)
  - **Pune**: Mechatronics, Formula Racing & Human-Centered UX (Hinjewadi Sahyadri Hills)
  - Switching campuses dynamically updates local campus imagery, placement stats, dean messages, signature research labs, and contact desks.

- 💬 **Interactive Student Ambassador & Admissions Desk ("Ask BIT")**:
  - Chat directly with **Priya Sharma** (Final Year CSE-AI & Chief Student Ambassador).
  - Answers questions on admissions, cutoffs, 100% scholarships, ₹54.2 LPA placement records, hostel rooms (AC/Non-AC), mess food, campus transfers, and fests.
  - Features real-time typing animation, suggested inquiry chips, voice synthesis capability, copy answers, and feedback triggers.

- 💰 **Tuition & Scholarship Calculator**:
  - Live slider for Class 12th Board Exam percentage (60% to 100%).
  - Entrance exam ranking selector (JEE / BSAT / State CETs).
  - Living options (Day Scholar, Non-AC Shared, Deluxe AC).
  - Instant calculation of tuition discount, 4-year savings, and printable **Official Scholarship Pre-Approval Certificate**.

- 🎫 **Digital Campus Visit Pass Generator**:
  - Select campus, date, and preferred morning/afternoon slot.
  - Instantly issues an official digital visitor pass with barcode and security gate entry instructions.

- 📌 **Live Campus Notice Board & "Day in the Life" Timeline**:
  - Real student council announcements, placements updates, and hackathon schedules.
  - Interactive student day timeline from 07:30 AM sunrise filter coffee to 09:30 PM hackathons and dorm study sessions.

- 🎨 **Human-Centric & Dynamic Design**:
  - Modern typography: Outfit + Plus Jakarta Sans + Caveat (handwritten accents).
  - Dark / Light mode toggle with persistent state.
  - Interactive reaction physics with floating emoji particles.

---

## 🚀 Running Locally

This project is built with vanilla HTML5, CSS3, and JavaScript, requiring zero external build steps.

To run the built-in lightweight server:
```bash
node server.js
```

Open your browser at:
```
http://localhost:3000
```
